# ابتكار — الموقع الجديد (4 أقسام مستقلة)

موقع HTML/CSS/JavaScript ثابت، عربي RTL ومتوافق مع Vercel وGitHub بدون npm أو إعداد Build.

## تركيب الأقسام

- `/` المنفذ الوحيد الذي يعرض روابط الأقسام الأربعة.
- `/finishing/` تشطيبات وصيانة، وتحتها `/from-scratch/` و`/home-maintenance/`.
- `/ac/` تكييفات، وتحتها `/used/` و`/installation/` و`/maintenance/` و`/relocation/`.
- `/robabekia/` روبابيكيا، وتحتها `/appliances/` و`/washing-machines/` و`/refrigerators/` و`/furniture/`.
- `/scrap/` الخردة، وتحتها `/copper/` و`/aluminum/` و`/iron/` و`/plastic/`.

## العزل والتنقل

* الصفحة الرئيسية فقط تحتوي روابط إلى الأقسام الأربعة.
* صفحة بداية كل قسم تحتوي تنقلًا خاصًا بصفحات نفس القسم فقط.
* الصفحات الداخلية لا تحتوي على قائمة الموقع العامة. الشعار بها يعود لصفحة بداية القسم نفسه، والروابط ذات الصلة تبقى داخل القسم.
* العزل هنا **عزل روابط تنقل**، وليس منعًا تقنيًا لزيارة الرابط مباشرة. منع الوصول بين الأقسام غير قابل للتحقيق بموقع عام مفتوح للفهرسة.

## المحتوى والتواصل

* لكل صفحة عنوان H1 وtitle وdescription وcanonical وOG Image وصورة هيرو محلية وبيانات منظمة ومحتوى متعدد الأقسام وأسئلة شائعة.
* الصور الأصلية بصيغة SVG وبنسخ WebP ومقاسات مشاركة JPEG محلية داخل `assets/art`. الصور رسومية توضيحية وليست صورًا فوتوغرافية.
* صورة وحدة التكييف الحقيقية الوحيدة من الموقع القديم محفوظة داخل `assets/images/ac-outdoor.webp`، ويمكن استبدال الرسومات بصور ميدانية مرخّصة لاحقًا.
* الرقم الرئيسي: `01157016620` والبديل `01156891501`، من النسخة الأصلية. عدّل الرقم في ملفات HTML و`assets/site.js` قبل النشر إذا تغيّر.
* أزرار واتساب واتصال تعمل مباشرة. نموذج الاستعلام يكوّن رسالة واتساب من بيانات المستخدم بدون خادم ولا حفظ البيانات.
* الضغط على CTA يرسل `eptekaar_contact` إلى `dataLayer` **فقط إذا كان GA/GTM مثبتًا بالفعل**. لا توجد أداة تحليلات مثبتة تلقائيًا.

## النشر على Vercel

1. ارفع **محتويات هذا المجلد** إلى جذر مستودع GitHub (وليس مجلدًا إضافيًا يحيط بها).
2. وصل GitHub بـVercel أو استخدم المشروع الموجود نفسه.
3. اختر Framework Preset: `Other`، واترك Build Command فارغًا وOutput Directory افتراضيًا (الجذر).
4. `vercel.json` يوجه الروابط القديمة `/ac-new/` و`/ac-used/*` بتحويلات 301، ويضبط اللاحقة `/`.
5. افحص في المتصفح: `/` و`/finishing/` و`/ac/` و`/robabekia/` و`/scrap/` وصفحات التفاصيل.
6. بعد النشر أرسل `https://eptekaar.vercel.app/sitemap.xml` إلى Google Search Console.
7. حدّث Final URL لكل إعلان Google Ads بالمسار الموافق له، واربط وسوم التحويل إن أردت تتبع تواصل واتساب والمكالمات.

## SEO

- فهرسة جوجل ليست مضمونة؛ المحتوى مصمم ليكون أصليًا، منظمًا، وملائمًا لنية البحث، لكنه يحتاج أدلة واقعية مثل صور أعمال وخدمات فعلية ومراجعات حقيقية وتوضيح نطاق التغطية.
- المخزون والأسعار والمواعيد متغيرة وغير معروضة كوعود ثابتة.
- لتغيير الدومين لاحقًا، استبدل `https://eptekaar.vercel.app` في metadata وsitemaps بكل عناوين الموقع النهائية.
- لا يوجد كود إعلاني أو مكتبات خارجية أو صور مستضافة على مزود خارجي.

## فحص محلي

`python -m http.server 8000` من داخل جذر المشروع، وافتح `http://localhost:8000` (المسارات ذات `/` تعمل بالمجلدات و`index.html`).
